# Scór pobail
### *"Community Score"*

`scór` score / tally · `pobail` of the community / public

### Uirlis abhair sibhialta

Is taiscéalíocht le haghaidh an am idir spásanna an repo seo. Tá rochtan riachtanas chun chathair feidhmiú - chaithfidh a bheith na riachtanas laethúla le fáil ar gach duine.  Is é an miain don uirlis seo chun léargas a cuir ar an am a tógann sé chun súil idir spásanna.

### Civic distance tool

This is an exploration of the time between spaces. Easy accessibility is key to a functioning city, with ready availability to every day needs for every person. This tool is intended to visually map and highlight the time taken to walk between spaces.
